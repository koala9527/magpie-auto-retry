# 1.0.1 验证记录

日期：2026-11-18。对照版本：1.0.0。

## 改了什么

- 按用户提供的模型指纹页面参考，使用浅灰背景、白色面板、细边框、横向导航和紧凑双栏。取消彩色装饰，正文 12px、标题 18px，保留深色主题和键盘焦点。
- 总览与设置常驻显示费用、风控和封号风险；连接失败时也显示。
- 参数旁说明默认值、作用和范围，编辑后的规则预览使用通俗表述。
- 左侧说明请求从 Agent 到提供商的流程、默认等待序列，以及成功、永久错误、部分输出和取消时如何结束。
- 中英文 README 同步说明。没有改重试引擎、默认参数、统计数据格式或权限边界。
